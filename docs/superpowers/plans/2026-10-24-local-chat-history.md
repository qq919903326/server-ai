# 默认本地会话存储实施记录

用户需求：增加是否存储 Session 的设置，服务端默认关闭；会话内容保存在本地。

- [x] 服务端全局设置默认 false，环境 STORE_SESSIONS 默认 false；请求还需显式 store_session=true 才能写入。
- [x] 关闭时聊天仅在请求内存执行，sessions/chat runs 均不写入；多轮上下文由受限 user/assistant history 随请求提供。
- [x] 浏览器 IndexedDB 始终保存会话、工具过程和聊天运行记录，刷新恢复；设置界面明确显示存储位置。
- [x] 旧服务器记录先在本地事务中导入，再按 ID+版本 ACK 删除；冲突保留双方本地副本，失败不删除。
- [x] 在途请求同时检查最初 opt-in 与当前设置，关闭后不能重新写回被迁移的数据。
- [x] 浏览器测试默认自动运行隔离临时数据库，避免会话迁移测试访问真实用户历史。
- [x] 真实 HTTP 模型夹具验证本地刷新恢复和第二轮上下文，迁移冲突测试覆盖 session 和 chat run。

范围：聊天会话及聊天运行记录；工作流记录、配置和文件库配对元数据仍由服务端保存。浏览器清除网站数据会清除本地历史，不删除外部备份。
