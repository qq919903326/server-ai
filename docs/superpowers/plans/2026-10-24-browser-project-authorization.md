# 浏览器本地项目授权实施记录

用户选择：不下载程序、不填写设备 ID；点击「添加本地项目」时触发系统目录选择与浏览器只读授权。

- [x] 使用 showDirectoryPicker({mode:'read'})，保证在用户点击中直接调用。
- [x] 原生目录句柄与自动配对信息保存在 IndexedDB，后台只查询权限，失效后由用户再次选择目录。
- [x] 浏览器 WebRTC DataChannel 直接响应只读文件工具，复用既有服务端项目工具和信令，不预上传整个目录。
- [x] 全局连接生命周期覆盖聊天/工作流切页，刷新恢复；Web Locks 选主协调多标签页，存储锁合并授权更新。
- [x] 旧轮询不再删除授权句柄，回归测试覆盖迟到快照与新增授权并发。
- [x] 真实浏览器 OPFS 句柄、IndexedDB、WebRTC 和工作流读取验证；系统目录选择窗口由测试桩代替。
- [x] 取消和拒绝授权不创建项目或配对，权限撤销不触发后台授权提示，不支持写入操作。

边界：File System Access 与 Web Locks 浏览器支持，HTTPS（localhost 除外）；至少一页保持打开。公网网络仍需配置 ICE，真实系统权限窗口及跨公网 NAT/TURN 未在此环境验证。
